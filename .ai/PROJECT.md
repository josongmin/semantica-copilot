# Semantica Copilot 프로젝트

## 개요
Semantica Codegraph 기반 AI 코딩 어시스턴트 프로젝트

## 프로젝트 목적
- Semantica Codegraph의 코드 지식을 활용한 지능형 코딩 지원
- LLM 기반 코드 생성, 리팩토링, 설명 제공
- 개발자 워크플로우 통합

## 기술 스택
- Python 3.10+
- Semantica Codegraph (코드 지식 엔진)
- LLM Integration (OpenAI, Anthropic 등)

## 개발 규칙
- Python 3.10+ 타입 힌팅 필수
- 포트/어댑터 패턴 준수
- 모듈 간 순환 의존성 방지

## 문서화 규칙
- 마크다운 파일은 `.temp` 폴더에 생성
- 핵심만 간결하게 작성 (필수 내용만 포함)
- 이모지 사용 금지
